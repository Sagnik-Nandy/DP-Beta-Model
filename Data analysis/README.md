# Data analysis

Applies the same estimators as `../Numerical experiments/` to a real
communication network — the Enron email hypergraph — instead of synthetic
data, matching Section 6 (and Appendix E) of the paper. Task: link
prediction (held-out hyperedges vs. sampled non-edges), benchmarked across
`eps in {0.001, 0.01, 0.1, 1.0}` at 2-, 3-, and 4-uniform hyperedge orders.
See the repo root README for the full method description, paper link, and
install requirements.

## Layout

```
Data analysis/
├── data/email-Enron/   The public Enron email hypergraph dataset (raw +
│                        derived 2-/3-/4-uniform hyperedge lists)
└── codes/               Data loaders (raw simplices -> per-order edge CSVs)
                          and link-prediction notebooks, one per order
```

| Notebook | Reads | Writes |
|---|---|---|
| `enron_email_data_loader_order2.ipynb` | `data/email-Enron/email-Enron-{nverts,simplices,times}.txt` | `data/email-Enron/enron_order2_edges.csv` |
| `enron_email_data_loader_order3.ipynb` | same | `data/email-Enron/enron_order3_edges.csv` |
| `enron_email_data_loader_order4.ipynb` | same | `data/email-Enron/enron_order4_edges.csv` |
| `link_prediction_order2.ipynb` | `enron_order2_edges.csv` | `link_prediction_results_order2.csv` |
| `link_prediction_order3.ipynb` | `enron_order3_edges.csv` | `link_prediction_results.csv` |
| `link_prediction_order4.ipynb` | `enron_order4_edges.csv` | `link_prediction_results_order4.csv` |

`enron_email.ipynb` is an early prototype of the loader, superseded by the
three `enron_email_data_loader_order*.ipynb` notebooks above; kept for
reference.

Run order: the matching `enron_email_data_loader_order*.ipynb` first
(produces the edge CSV under `data/email-Enron/`, already included in this
repo), then the corresponding `link_prediction_order*.ipynb`.

Since the true `M` (the box constraint on beta) is unknown for real data,
the link-prediction notebooks use the conservative choice
`M = 2*sqrt(log n)` and a fixed, empirically-stable step size `eta = 0.005`,
rather than the theoretical worst-case rate used in
`../Numerical experiments/`.

Each `link_prediction_order*.ipynb` writes its results table to a CSV in
`codes/` (see table above); these are gitignored and regenerated by running
the notebook.

## Data source and provenance

`data/email-Enron/` is the public dataset from Benson et al. (2018),
originally released at https://www.cs.cmu.edu/~./enron/, this copy via
https://www.cs.cornell.edu/~arb/data/. Each simplex is an email; its nodes
are the Enron employees who sent or received it. See
`data/email-Enron/DATA-DESCRIPTION.txt` for the exact file encoding.

The original dataset also ships a node-labels file mapping node ids to
employees' real names and email addresses. It is not needed by any script
here (only `nverts`/`simplices`/`times` and the derived edge CSVs are used)
and is intentionally omitted from this repository.
